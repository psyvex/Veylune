# Veylune Marketing Experience

The public root route presents the product story and links into the local Studio at `/studio`. The marketing page describes camera capture, refinement progress, and local image-set organization without implying that imported image sets already produce a reconstruction.

The page uses a responsive product-led layout: a spatial scan hero, capture and import feature cards, a three-step workflow, and a local-first privacy section. CSS motion gives the hero mesh, scan sweep, map points, orbital rings, and section reveals a sense of depth. The compact navigation supports keyboard activation, and section entrance motion is removed for visitors who prefer reduced motion.
