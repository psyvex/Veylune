# Veylune Marketing Experience

The public root route presents the product story and links into the local Studio at `/studio`. The light-only marketing page describes camera capture, refinement progress, and local image-set organization without implying that imported image sets already produce a reconstruction.

The page uses a responsive product-led layout: a single full-width interactive spatial scene, capture and import feature cards, a three-step workflow, and a local-first privacy section. The canvas uses perspective-projected room geometry to illustrate scanning, camera alignment, and map refinement; visitors can switch stages or orbit the scene by dragging and with the arrow keys. The scene pauses outside the viewport and honors reduced-motion settings. CSS motion carries through the feature illustrations and section reveals, while the compact navigation supports keyboard activation.
